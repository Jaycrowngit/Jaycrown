## The problem

Small businesses lose sales because WhatsApp messages go unanswered after hours, and hiring support staff for every channel isn't viable.

## My role

Designed and built the agent pipeline end to end.

## Architecture

- **WhatsApp Cloud API webhooks** feed an async worker queue.
- An **LLM agent with tools** — product lookup, order capture, FAQ retrieval — grounded in the business's own data.
- **Human handoff** when confidence is low or the customer asks for a person.

## Key decisions

- **Tools over free text:** the model calls typed functions for anything that touches data, so it can't invent prices or stock.
- **Bounded conversation memory** keeps context relevant and cost predictable.
